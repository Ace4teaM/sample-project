# sample-project

Ce dépôt prépare un PoC C++ pour démontrer la faisabilité technique de :

1. trier des bytes en mémoire directement dans la zone fournie ;
2. conserver la même adresse mémoire avant et après le tri ;
3. exporter le résultat trié dans un fichier texte (une valeur décimale par ligne).
